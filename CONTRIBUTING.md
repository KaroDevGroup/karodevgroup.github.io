# Contributing to DaBoyzApp


Thank you for your interest in contributing to **DaBoyzApp**.

DaBoyzApp is a Windows desktop application built for the DaBoyz community. Contributions that improve stability, usability, documentation, performance, or features are welcome.

Before contributing, please read this document so submissions can be reviewed as efficiently as possible.

</div>

---

## </> Ways to Contribute

You can contribute to DaBoyzApp by:

- Reporting bugs
- Suggesting new features
- Improving documentation
- Fixing existing issues
- Improving application performance
- Improving UI or UX
- Improving accessibility
- Submitting code changes
- Reporting security vulnerabilities responsibly

---

## </> Before You Start

Before creating an issue or pull request:

1. Check existing issues to make sure the problem or suggestion has not already been reported.
2. Make sure you are using the latest available version of DaBoyzApp.
3. Confirm that the issue can be reproduced when possible.
4. Include enough information for maintainers to understand the problem.

For security vulnerabilities, do **not** create a public issue.

Please follow the instructions in `SECURITY.md`.

---

# </> Reporting Bugs

When submitting a bug report, include as much useful information as possible.

Please include:

- DaBoyzApp version
- Windows version
- System architecture
- What you were doing when the problem occurred
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Screenshots, videos, or logs if applicable
- Any error messages displayed

Example:

```text
DaBoyzApp Version: 0.1.0-beta
Windows Version: Windows 11
Architecture: x64

Steps to reproduce:
1. Open DaBoyzApp
2. Navigate to the Gaming Database
3. Select a game
4. Application closes unexpectedly

Expected:
The selected game page should open.

Actual:
The application closes.
